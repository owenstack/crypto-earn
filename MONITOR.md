# Dry-run monitor

The monitoring loop is supervised as systemd unit `cex-dry-run-monitor.service`, running process `cex-dry-run-monitor` from `scripts/monitor-dry-run.sh`. Each cycle runs `scripts/check-dry-run.sh` every 600 seconds and updates `/tmp/cex-dry-run-monitor.heartbeat`; output is retained in `/tmp/cex-dry-run-monitor.log`. A read-only liveness check may run `systemctl is-active cex-dry-run-monitor.service` and/or inspect the heartbeat mtime. A failed health cycle stops the compose stack and exits with status 75, which systemd treats as an intentional incident halt and leaves stopped for human review; unexpected monitor failures remain restartable.
